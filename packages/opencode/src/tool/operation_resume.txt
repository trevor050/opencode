Create a compact restart brief for a ULMCode operation from disk state.

Use this before resuming a long-running operation after context compaction, process restart, handoff, or uncertainty about current state. The brief lists checkpoint state, health gaps, active/background tasks, recommended follow-up tools, and a continuation prompt that can restart work without rereading every artifact manually.

For unattended runs, pass `staleAfterMinutes` so stale checkpoints and stale background jobs are called out before new work starts. Pass `recoverStaleTasks: true` when restartable stale/error/cancelled background lanes or supervised commands should be relaunched immediately from saved metadata before the refreshed brief is returned. Use `maxRecoveries` to cap automatic recovery breadth.

When recovery restarts a stale lane, do not narrate an open-ended wait. Poll the recovered task once with `task_status` using `wait: true` and a bounded timeout. If it is still running and no fresh lane-owned artifacts appeared, call `operation_run` with `block_lane`/`skip_lane` and a precise reason rather than waiting in prose or reusing stale evidence.
